# אתר מודעות לאלימות נגד נשים

אתר סטטי פשוט ב-HTML/CSS/JavaScript.

## הרצה
פתחו את `index.html` בדפדפן.

## העלאה ל-GitHub Pages
1. צרו Repository חדש ב-GitHub.
2. העלו אליו את `index.html`, `style.css` ו-`script.js`.
3. היכנסו ל-Settings של ה-Repository.
4. בחרו Pages.
5. תחת Build and deployment בחרו `Deploy from a branch`.
6. בחרו את `main` ואת התיקייה `/ (root)`.
7. לחצו Save.
8. אחרי שהפרסום מסתיים, GitHub יציג את כתובת האתר.
